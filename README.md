# Research Data for CATENA Submission

This repository provides partial, non-sensitive research data supporting the manuscript:
“Enhancing erosion resistance of purple soils using colluvial deposits”.

## Included datasets
- Displacement–time data (Y-direction) for six schemes (S0–S5) from PFC3D fluid–solid simulations.
- Figure 18–19 summary table (runoff rate and sediment concentration data).

## Notes
These datasets correspond to the data shown in Figures 18, 19, and 21 of the manuscript.
Only processed and non-sensitive data are publicly released here.

Full raw datasets, including:
- complete scouring time series,
- high-frequency HHT energy spectra,
- full-resolution displacement/velocity outputs,
- complete PFC3D model files,
are restricted due to project confidentiality and can be provided upon reasonable request.
